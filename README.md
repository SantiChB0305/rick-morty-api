# Rick & Morty Explorer API

Aplicación web desarrollada con Angular, FastAPI y MongoDB Atlas.

- **Demo Frontend:** https://rick-morty-1q43h379x-berserk6.vercel.app/
- **API Backend:** https://rick-morty-api-1-0oqu.onrender.com/

## Ejecución Local

1. **Backend:** `cd backend-rickmorty` -> `uvicorn main:app --reload`
2. **Frontend:** `cd frontend-rickmorty` -> `npm start`
